---
name: Combined result grading
description: The grading and pass/fail rule for the combined-results report
---

Combined results use the raw overall percentage from grand obtained marks divided by grand maximum marks. The grade scale is A+ (90+), A (80–89), B+ (70–79), B (60–69), C (50–59), D (30–49), and F (below 30). Display percentages preserve one decimal when needed, so 590/2000 shows 29.5%; pass/fail uses the same raw percentage.

**Why:** Rounding the displayed percentage made 590/2000 appear as 30%, which was misleading because the raw result is 29.5% and correctly fails the 30% threshold.

**How to apply:** Keep raw percentage for grade, pass/fail, and ranking decisions; format it as an integer when exact or one decimal when fractional. Do not add per-subject pass requirements to the combined-results report unless that policy is explicitly requested.
