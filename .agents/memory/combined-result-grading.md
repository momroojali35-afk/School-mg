---
name: Combined result grading
description: The grading and pass/fail rule for the combined-results report
---

Combined results use the raw overall percentage from grand obtained marks divided by grand maximum marks. The grade scale is A+ (90+), A (80–89), B+ (70–79), B (60–69), C (50–59), D (30–49), and F (below 30). Pass/fail uses the same raw percentage, so a displayed 30% can still be F when the actual percentage is 29.5%.

**Why:** The combined-results table originally required every subject in every selected exam to reach 30%, causing students with passing overall percentages to display FAIL. Rounding the percentage before pass/fail also risks incorrectly passing values below 30%.

**How to apply:** Keep raw percentage for grade and pass/fail decisions; round only for display. Do not add per-subject pass requirements to the combined-results report unless that policy is explicitly requested.
